What is BST?

A Binary Search Tree (BST) is a tree data structure where values smaller than the root are placed on the left side and values greater than the root are placed on the right side.

BST Operations:

1. Insert contact based on name
2. Search contact using name
3. Inorder traversal displays contacts alphabetically
4. Each node contains one contact
