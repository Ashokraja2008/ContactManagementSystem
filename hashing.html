⚡ Hashing

Fast contact searching using Hash Table

What is Hashing?

Hashing is a data structure technique used to store and retrieve data quickly. A hash function converts a key into an index in a hash table.

Hashing Operations:

1. Take the contact name as the key.
2. Calculate a hash value from the name.
3. Store the contact in the corresponding bucket.
4. Use the same hash function during searching.
5. Handle collisions using separate chaining.
